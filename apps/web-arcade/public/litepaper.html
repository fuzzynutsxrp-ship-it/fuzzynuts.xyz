1. Overview

Fuzzynuts ($NUT) is a community-driven meme coin built natively on the XRP Ledger (XRPL). With a fixed supply of 321 billion tokens and a permanently blackholed issuer account, $NUT is designed to be fun, transparent, and impossible to rug.

The project combines meme culture with the XRPL's speed, low fees, and built-in decentralized exchange to create an accessible, community-first token with no smart contract risk.

2. Why the XRP Ledger?

$NUT is a native XRPL token, not a smart contract. This provides distinct advantages:

  • 3-5 second settlement — near-instant transactions
  • ~$0.0002 per transaction — negligible fees
  • Built-in DEX — no bridges, no wrapping, no third-party contracts
  • Native AMM — XRPL's protocol-level automated market maker (not a dApp)
  • No smart contract risk — token logic lives in the protocol itself
  • Carbon neutral — XRPL's consensus mechanism uses minimal energy

💀 Blackholed Issuer — Zero Inflation Guarantee

The issuer account has been permanently blackholed by disabling the master key and setting the regular key to a provably unspendable address (rrrrrrrrrrrrrrrrrrrrBZbvji). This means:

  • No new tokens can ever be minted — the supply is fixed forever
  • No one can modify the issuer — including the original creators
  • Verifiable on-chain — anyone can confirm this on any XRPL explorer
