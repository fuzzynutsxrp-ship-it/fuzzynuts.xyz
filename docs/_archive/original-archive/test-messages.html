🐿️ postMessage Test Harness

Simulate & debug messages between games ↔ GameWrapper.tsx

📋 Message Log

How to use this harness:

From a game page: Include <script src="../fuzzy-score.js"></script> in your game, then call:
FuzzyScoreSubmit('mario', 42069, 120)

Message contract (game → GameWrapper):
window.parent.postMessage({ type: 'FUZZY_SCORE_SUBMITTED', success: true }, '*')

Message contract (game → LoadingOverlay):
window.parent.postMessage({ type: 'gameReady' }, '*')

Message contract (GameWrapper → game):
{ type: 'setMute', muted: true/false }
