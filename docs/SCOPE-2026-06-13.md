## E. Top 5 risks if launched today

1. **Live site shows third-party MMOs** — `games.json` on Vercel still contains 40 external games; clicking any carousel card leads to 404s. Users see competitor games on the homepage.

2. **Scores can be spoofed** — No HMAC verification on score submissions. Anyone can POST arbitrary scores to `/api/scores` without cryptographic proof. Leaderboard is trivially gameable.

3. **Wallet auth is mocked** — `auth.js` sends a hardcoded wallet address with `MOCK_SIGNATURE_`. No real XRPL wallet verification. Any user can impersonate any wallet.

4. **Score caps are inconsistent** — Three copies of SCORE_CAPS disagree. The server accepts scores that the client would reject (and vice versa). Some games have caps 10-100x higher than intended.

5. **Hot-wallet seed is a single env var** — NUT distributor seed (`COMMUNITY_NUT_JAR_SEED`) is a single Railway secret with no multisig or RegularKey protection. If Railway is compromised, all prize funds are at risk.
