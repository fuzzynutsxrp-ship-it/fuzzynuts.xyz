# Fuzzynuts documentation

Organised by the [Diátaxis](https://diataxis.fr) framework. Find what you
need by what you want to do:

- [**Tutorials**](./tutorials/) — Learning-oriented. "By the end of this you will…"
- [**How-to guides**](./how-to/) — Task-oriented. "How do I…?"
- [**Reference**](./reference/) — Information-oriented. APIs, schemas, env vars.
- [**Explanation**](./explanation/) — Understanding-oriented. Why it works this way.

Plus:

- [Architecture Decision Records](./adr/) — Append-only history of why.
- [Runbooks](./runbooks/) — On-call procedures.
- [Project status](./STATUS.md) — Auto-generated; do not hand-edit.

Files under [`_archive/`](./_archive/) are kept for history and are not maintained.
